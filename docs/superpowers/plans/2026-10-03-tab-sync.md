# Tab Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Editors showing the same document in several tabs of one browser converge live with no server: content, a few settings, and the personal open/closed state of toggles.

**Architecture:** A new core module `TabSync` bridges the always-alive Yjs document (`YjsManager.applyRemoteUpdate` / `onDocUpdate`) to a `BroadcastChannel`. A Web Lock picks one leader tab per document; it answers joining tabs and is the only tab that saves. A joining tab adopts the leader's state by resetting its Y.Doc and applying the leader's full update — the same reset path collaboration's relineage uses. Toggle open state moves out of saved data into a new personal, per-browser `api.viewState` store.

**Tech Stack:** TypeScript, Yjs 13, BroadcastChannel, Web Locks API, localStorage, Vitest (jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-03-tab-sync-design.md` (research evidence: `docs/plans/2026-10-02-tab-sync-research.md`). Read both before starting.

## Global Constraints

- TDD: every behaviour is a failing test first, watched RED, then the minimal code (root `CLAUDE.md`).
- On by default. `tabSync: false` turns all of it off. `tabSync: { settings: false }` turns only the settings channel off.
- With `collaboration` set, tab sync never activates. `documentId` is still accepted.
- Identity order: `documentId` (host) → `OutputData.id` → no sync.
- Channel key in AUTO mode (no `documentId`) = id + `location.pathname`, no query, no hash. EXPLICIT `documentId` keys on the id alone (the path guard exists only to keep copied auto ids apart; the host promises a `documentId` is unique — see "Deviations" at the end).
- Auto mode joins only when the document came through `persistence.load` (or minted its own id and saved it) and is not empty. A document passed through raw `data` never auto-joins.
- Only the leader calls `persistence.save` / `onSave`. `onChange` fires everywhere with `origin`. A passive tab never arms the close prompt.
- Newer version wins at join. Versions are opaque strings (ETags), so "newer" = a version the leader has never seen (loaded, saved, or broadcast). No version → open tabs win.
- Join timeout: 3000 ms → the tab stays separate, never seeds by force.
- Toggle / toggleable heading: `isOpen` is never read from input and never written to output; removed from `types/tools/toggle.d.ts`; default collapsed. No migration and no BREAKING label (user decision).
- Settings channel syncs: locale, theme MODE, width. Never: tokens, readOnly, placeholder, toolbar, tools, media playback position.
- Comments: short, only what silently breaks if changed (root `CLAUDE.md`).
- Unit tests: no `any`, no `!`, no `@ts-ignore`; `vi.clearAllMocks()` in `beforeEach`; `vi.restoreAllMocks()` in `afterEach`.
- E2E: no CSS class selectors; `data-blok-testid` or roles.
- While iterating run ONLY the related tests: `yarn test <file>` (single file per invocation — multi-path vitest skips files, see memory `blok-agent-gate-traps`). Lint only changed files: `yarn eslint <files>`.

## Review Focus

1. **Typing while a tab update reconciles the same block** — the user expects their keystroke saved and labelled `local`; a reconcile window can mislabel it `tab` (Task 11 pins: a keystroke inside an open remote window that `claimChangeAnnouncement` marks user-typed is labelled `local`).
2. **Leader closes mid-typing** — the expectation is no lost edit; the successor must save edits newer than the last saved version (Task 13 pins: successor with unsaved tab edits calls `persistence.save` once after taking the lock).
3. **Two tabs open the same document at the same instant** — expectation: one leader, one follower, no duplicated blocks (Task 15 e2e pins: two pages opened with `Promise.all`, block count equals the source document's).
4. **A tab edits before its join answer arrives** — expectation: the edit is not lost; the tab stays separate rather than reset (Task 13 pins: local update before answer → role `solo`, content kept).
5. **Locale changed while another tab is still loading** — expectation: no crash, the late tab simply keeps its boot locale (Task 17 pins: settings message before `start()` is ignored without throwing).

```ts
/** Bump when the message envelope changes: tabs on different versions must not merge. */
export const TAB_SYNC_PROTOCOL = 1;

export type IdSource = 'host' | 'persistence' | 'minted' | 'data';

export interface TabKeyInput {
  documentId: string | undefined;
  recordId: string | null;
  idSource: IdSource;
  hasSaved: boolean;
  isEmpty: boolean;
  pathname: string;
}

/**
 * The BroadcastChannel / lock name tabs of one document share, or null when it
 * is not safe to sync. Auto mode adds the path: a host that copies a stored
 * document copies its id, and the copy usually lives at another path.
 * @param input - what this tab knows about its document
 */
export const resolveTabKey = (input: TabKeyInput): string | null => {
  if (typeof input.documentId === 'string' && input.documentId !== '') {
    return `blok-tab:${TAB_SYNC_PROTOCOL}:id:${input.documentId}`;
  }

  if (input.recordId === null || input.isEmpty) {
    return null;
  }

  const trusted = input.idSource === 'persistence'
    || (input.idSource === 'minted' && input.hasSaved);

  return trusted ? `blok-tab:${TAB_SYNC_PROTOCOL}:auto:${input.recordId}:${input.pathname}` : null;
};
```

```ts
export const VIEW_STATE_PREFIX = 'blok:view:';
export const VIEW_STATE_MAX_AGE_MS = 90 * 24 * 60 * 60 * 1000;

export interface ViewStateStore {
  get(blockId: string, key: string): unknown;
  set(blockId: string, key: string, value: unknown): void;
  subscribe(blockId: string, key: string, listener: (value: unknown) => void): () => void;
  setScope(scope: string | null): void;
  destroy(): void;
}

interface StoredEntry { v: unknown; t: number }

const parse = (raw: string | null): StoredEntry | null => {
  if (raw === null) {
    return null;
  }

  try {
    const parsed: unknown = JSON.parse(raw);

    return typeof parsed === 'object' && parsed !== null && 't' in parsed && typeof parsed.t === 'number'
      ? { v: (parsed as { v?: unknown }).v, t: parsed.t }
      : null;
  } catch {
    return null;
  }
};

const defaultStorage = (): Storage | null => {
  try {
    return typeof localStorage === 'undefined' ? null : localStorage;
  } catch {
    return null;
  }
};

export const createViewStateStore = (options: {
  scope: string | null;
  storage?: Storage | null;
  now?: () => number;
}): ViewStateStore => {
  const storage = options.storage === undefined ? defaultStorage() : options.storage;
  const now = options.now ?? Date.now;
  const memory = new Map<string, unknown>();
  const listeners = new Map<string, Set<(value: unknown) => void>>();
  let scope = options.scope;

  const memoryKey = (blockId: string, key: string): string => `${blockId}:${key}`;
  const storageKey = (blockId: string, key: string): string | null =>
    scope === null ? null : `${VIEW_STATE_PREFIX}${scope}:${blockId}:${key}`;

  const notify = (id: string, value: unknown): void => {
    listeners.get(id)?.forEach((listener) => listener(value));
  };

  const sweep = (): void => {
    if (storage === null) {
      return;
    }

    try {
      const stale: string[] = [];

      for (let i = 0; i < storage.length; i++) {
        const key = storage.key(i);
        const entry = key !== null && key.startsWith(VIEW_STATE_PREFIX) ? parse(storage.getItem(key)) : null;

        if (key !== null && key.startsWith(VIEW_STATE_PREFIX) && (entry === null || now() - entry.t > VIEW_STATE_MAX_AGE_MS)) {
          stale.push(key);
        }
      }
      stale.forEach((key) => storage.removeItem(key));
    } catch {
      // Storage blocked: nothing to sweep.
    }
  };

  const onStorage = (event: StorageEvent): void => {
    if (scope === null || event.key === null || !event.key.startsWith(`${VIEW_STATE_PREFIX}${scope}:`)) {
      return;
    }

    const id = event.key.slice(`${VIEW_STATE_PREFIX}${scope}:`.length);
    const value = parse(event.newValue)?.v;

    memory.set(id, value);
    notify(id, value);
  };

  sweep();
  window.addEventListener('storage', onStorage);

  return {
    get: (blockId, key) => {
      const id = memoryKey(blockId, key);
      const persisted = storageKey(blockId, key);

      if (persisted !== null && storage !== null) {
        try {
          const entry = parse(storage.getItem(persisted));

          if (entry !== null) {
            return entry.v;
          }
        } catch {
          // Fall through to memory.
        }
      }

      return memory.get(id);
    },
    set: (blockId, key, value) => {
      const id = memoryKey(blockId, key);
      const persisted = storageKey(blockId, key);

      memory.set(id, value);
      if (persisted !== null && storage !== null) {
        try {
          storage.setItem(persisted, JSON.stringify({ v: value, t: now() }));
        } catch {
          // Quota or blocked storage: memory still holds it for this tab.
        }
      }
      notify(id, value);
    },
    subscribe: (blockId, key, listener) => {
      const id = memoryKey(blockId, key);
      const set = listeners.get(id) ?? new Set();

      set.add(listener);
      listeners.set(id, set);

      return () => {
        set.delete(listener);
      };
    },
    setScope: (next) => {
      scope = next;
    },
    destroy: () => {
      window.removeEventListener('storage', onStorage);
      listeners.clear();
    },
  };
};
```

3. `tryAcquire()` true → role `leader`; subscribe `onDocUpdate` → post `update`; listen for `hello`.
4. `tryAcquire()` false → role `joining`; post `hello { version }`; wait up to `JOIN_TIMEOUT_MS` for `state` or `yield` addressed `to` this tab id.
5. Leader on `hello`: wait for its own pending writes (`YjsManager.flushPendingBlockWrites()`); if the joiner's `version !== null` and the leader tracks versions and `!seen.has(version)` → post `yield { to }`. Else post `state { to, update: encodeStateAsUpdate(), versions: [...seen], version: current }`.
6. Joiner on `state`: if a local `onDocUpdate` fired since `start` (dirty before join, Review Focus 4) → role `solo`, keep content. Else `adopt(update)` (below); `seen` ← `versions`; `PersistenceVersionAccess.set(version)`; role `follower`; `lock.queue(signal)` → on resolve role `leader` and, if the doc has updates newer than the last `saved` (track a `dirtySinceSaved` flag set by any update and cleared by `saved`), call `ModificationsObserver` to save (Review Focus 2).
7. Joiner on `yield`: post `replace { update: encodeStateAsUpdate(), version }`; role `follower`; queue for the lock.
8. Any tab on `replace`: `adopt(update)`; `seen.add(version)`; `PersistenceVersionAccess.set(version)`.
9. Any tab on `update`: `YjsManager.applyRemoteUpdate(update, this.origin)` where `this.origin = { tabSync: true }` (ONE long-lived object — primitive origins are kept forever, see `collaboration/types.ts:128-131`). Set `dirtySinceSaved`.
10. Leader on its own `onSaved(version)`: `seen.add(version)`, post `saved { version }`. Followers on `saved`: `seen.add`, `PersistenceVersionAccess.set`, clear `dirtySinceSaved`.
11. Timeout with no answer → role `solo`, `ModificationsObserver.onRoleChanged('solo')`.
12. Read-only (`this.Blok.ReadOnly.isEnabled`) → never posts `update`/`replace`, never queues for the lock.
13. Every role change calls `ModificationsObserver.onRoleChanged(role)` and `BlockManager.setRemoteOriginLabel('tab')` once active.
14. A Yjs update that throws inside `applyRemoteUpdate` → log `warn` once, close channel, release lock, role `solo`.
15. `destroy()`: abort the queue, release the lock, close the channel, unsubscribe.

`adopt(update)`:

```ts
private async adopt(update: Uint8Array): Promise<void> {
  const { BlockManager, ModificationsObserver, YjsManager } = this.Blok;

  // Same order as Collaboration.resetForRelineage: clear the DOM without
  // touching the document, then swap to a fresh Y.Doc, then let the leader's
  // state materialise through the ordinary remote path.
  ModificationsObserver.disable();
  try {
    await BlockManager.clear(false, { skipYjsSync: true });
    YjsManager.resetForRelineage();
    YjsManager.applyRemoteUpdate(update, this.origin);
  } finally {
    ModificationsObserver.discardPendingChanges();
    ModificationsObserver.enable();
  }
}
```

## Deviations from the spec (flag to the user at handoff)

1. **Explicit `documentId` keys on the id alone, not id + path.** The spec puts the path in the key in general. The path only protects copied AUTO ids; with an explicit, host-promised-unique `documentId` it would only break "same document at another path" for no gain.
2. **`onChange` `origin` has a third value, `'remote'`,** for collaboration peers. The spec lists `'local' | 'tab'`; without `'remote'` a collaboration peer's edit would be labelled `local`, which is false.
3. **Personal state is a generic `api.viewState`** with storage key `blok:view:<scope>:<blockId>:open` instead of the spec's `blok:open:<docKey>:<blockId>`. Same behaviour; one generic lever instead of a toggle-only one (root `CLAUDE.md`: add the generic lever).
4. **The join "write gate" is implemented as adopt-by-reset.** A joining tab renders its own load into a LOCAL Y.Doc that is never broadcast, then swaps to a fresh Y.Doc holding the leader's state (the collaboration relineage path). Nothing the joiner seeded reaches another tab, which is the spec's guarantee.
5. **"Newer version wins" means "a version the leader has never seen".** ETags are opaque, so order cannot be compared; a version unknown to every open tab can only have come from a save made elsewhere after they loaded.
