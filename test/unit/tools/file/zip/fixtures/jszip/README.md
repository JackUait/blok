# JSZip reference archives

Copied from `test/ref/` of JSZip (https://github.com/Stuk/jszip), commit 609d95f.
The zip reader tests read them to check it behaves like JSZip.

`extra_filed_non_standard.zip` is left out (23 MB). `read-zip.test.ts` builds a small archive with the same odd extra fields instead.
